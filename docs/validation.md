# Code and data delivery validation

The supported entry point validates observations, recomputes statistics and renders all six main figures without manuscript files or TeX. `--smoke` and `--all` retain the existing training and analysis paths. `--skip-tex` is a compatibility no-op; `--compile-reference` has been removed.

Publication TeX, compiled papers and reference figure attachments have been removed from the current repository tree. The standalone `supp_training_cost.pdf` generated by the renderer is a diagnostic of Fig.6d, not a separate supplementary figure. The rendering pipeline draws its own schematics and does not read prebuilt paper figures.

Published-data checks concern supplied observations only. Fresh-run configuration/shape/mask checks do not automatically establish scientific reproduction. The full 923-run training protocol is unchanged and has not been repeated for this packaging change.

The latest packaging checks are recorded in [code_data_only_validation.json](code_data_only_validation.json). Earlier [validation narrative](history/validation_before_code_data_only_20261023.md), `current_validation.json`, `current_source_manifest.json` and `docs/validation/` files describe historical packaging states, including now-removed publication attachments; they are provenance records, not the current file inventory.
